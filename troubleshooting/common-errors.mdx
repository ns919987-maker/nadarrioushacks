---

NitroType Cheat v2 surfaces clear error messages when something goes wrong, but knowing what each one means and how to resolve it isn't always obvious. This page covers every common error you may encounter, its cause, and the exact steps to fix it.

<AccordionGroup>

  <Accordion title="WebView2 Component Not Installed">
    **Error message:** `You don't have the Microsoft WebView2 Component installed. This is a requirement to run the cheat. Please install it then run the cheat again.`

    **Cause:** The Microsoft WebView2 Runtime is not installed on your machine. NitroType Cheat v2 uses WebView2 to embed the browser window, so it cannot start without it.

    **Fix:**
    1. Visit [https://developer.microsoft.com/en-us/microsoft-edge/webview2/](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).
    2. Download and run the WebView2 Runtime installer.
    3. Once the installation finishes, relaunch NitroType Cheat v2.

    <Warning>
      This is a fatal error — the app exits automatically after you dismiss the dialog. You must install the WebView2 Runtime before the cheat can open.
    </Warning>
  </Accordion>

  <Accordion title="Unable to Load WebViewLoader2.dll">
    **Error message:** `Unable to load DLL WebViewLoader2.dll or one of its dependencies. Are you using another program that requires it or running two versions of the cheat at once?`

    **Cause:** Another application on your machine is already using the WebView2 component, or you have two different versions of NitroType Cheat v2 running at the same time. This creates a conflict when loading the required DLL file.

    **Fix:**
    1. Check your taskbar and system tray for any other running copies of the cheat and close them.
    2. Close any other applications that embed a WebView2 browser (for example, some Electron-based apps or certain Microsoft Store apps).
    3. Relaunch NitroType Cheat v2.

    <Warning>
      Like the missing WebView2 error, this is a fatal startup error — the app exits immediately after you dismiss the dialog.
    </Warning>
  </Accordion>

  <Accordion title="The Game Hasn't Started Yet">
    **Error message:** `The game hasn't started yet.`

    **Cause:** You clicked the **Start** button before the race text had fully loaded in the embedded browser. The cheat needs the race text to be present and visible before it can begin typing.

    **Fix:**
    1. Wait for the race countdown to finish and for the full race text to appear on screen.
    2. Click **Start** only once the race is in progress and the text is visible in the browser.

    <Note>
      This is not a fatal error — dismiss the dialog and try again once the race text has loaded.
    </Note>
  </Accordion>

  <Accordion title="Enter a Race Before Starting">
    **Error message:** `Enter A race before starting the cheat.`

    **Cause:** You clicked **Start** while the embedded browser was not on the race page. The cheat checks the current URL before it begins, and if you're on the lobby, the home page, or any other URL, it shows this warning instead of running.

    **Fix:**
    1. Inside the embedded browser, navigate into an active race (the URL should be `nitrotype.com/race`).
    2. Once you're on the race page with the race text loaded, click **Start**.
  </Accordion>

  <Accordion title="Unable to Connect to Update Server">
    **Error message:** `Unable to connect to update server. A new version might be available. Cannot verify version.`

    This message also appears as: `Unable to connect to update server (` *status code* `). A new version might be available. Cannot verify version.` — the version with a status code means the server was reached but returned an unexpected response.

    **Cause:** The update check at startup could not reach or successfully communicate with the remote server. This can happen because your internet connection is down, a firewall is blocking the request, or the update server is temporarily unavailable.

    **Fix:**
    1. Check that your internet connection is working.
    2. If your connection is fine, the update server may simply be down or busy — dismiss the dialog and continue using the cheat normally.

    <Note>
      This error is **not fatal**. The app continues to run with full functionality even when the update check fails.
    </Note>
  </Accordion>

  <Accordion title="Could Not Load Configuration Files">
    **Error message:** `Could not load configuration files:` *(followed by error details)*

    **Cause:** The settings file saved from your last session is corrupt, missing, or in an unexpected format. This can happen after an abnormal shutdown or a failed update. This error only appears if the automatic reset of your settings also fails.

    **Fix:** Close and relaunch the app. It attempts to reset all settings to their defaults automatically. Once it recovers, reconfigure your preferred options:

    - Typing rate and typing rate variance
    - Accuracy and accuracy variance
    - Auto Start, Auto Game, and Use Nitros checkboxes

    Your settings will be saved correctly going forward once the corrupt file has been replaced.
  </Accordion>

  <Accordion title="Failed to Remove Page Frame from List">
    **Error message:** `Failed to remove WebviewIFrame ID from list` *(followed by error details)*

    **Cause:** An unexpected conflict occurred while navigating between pages in the embedded browser. When a page frame is unloaded, the cheat tries to clean it up internally — if multiple frames are unloaded at the same moment, this cleanup step can fail.

    **Fix:**
    1. Dismiss the error dialog.
    2. Close and reopen NitroType Cheat v2.
    3. If the error appears every time you navigate, try restarting your PC and relaunching the cheat.

    <Note>
      This error does not necessarily prevent the cheat from working in the current session, but restarting is the safest course of action.
    </Note>
  </Accordion>

</AccordionGroup>
