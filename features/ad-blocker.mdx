NitroType Cheat v2 ships with a built-in ad blocker that keeps the embedded browser clean and distraction-free while you race. Because the cheat runs NitroType inside its own WebView2-based window, it has full control over every request and every DOM element the page creates — meaning ads never get a chance to render, and upgrade prompts are silently swept away before you ever see them.

## How It Works

The ad blocker operates on two independent layers that run simultaneously whenever the cheat is open.

### Layer 1 — Network-Level Blocking

Every outbound request made by the embedded browser is checked against a built-in blocklist of known ad and tracking domains before it leaves your machine. Blocked domains include (among others):

- `doubleclick.net`
- `googletagmanager.com`
- `facebook.com` / `facebook.net`
- `cloudflareinsights.com`
- `pub.network`
- `qualaroo.com`
- `vuukle.com`

When a request matches a blocked domain, the cheat intercepts it and returns a `404 Resource Blocked by Client` response — the request never reaches the remote server and no ad content is downloaded.

### Layer 2 — DOM-Level Blocking

Even when an ad element slips through at the HTML level (for example, NitroType's own in-page upgrade prompts), a secondary script runs every **100 milliseconds** and forcibly removes any element that carries an ad-related CSS class. The classes targeted are:

| Class | What it removes |
|---|---|
| `.ad` | Generic ad containers |
| `.profile-ad` | Profile-page advertisement slots |
| `.goldTeaser` | NitroType's built-in Nitro/Gold upgrade banners |

Because this script loops continuously, even dynamically injected ad elements are removed within a fraction of a second of appearing.

## CAPTCHA Solver

Alongside the two-layer ad blocker, an automatic hCaptcha solver extension is bundled directly with the cheat. When NitroType presents a CAPTCHA challenge — for example, after repeated logins or suspicious activity — the extension detects it and solves it automatically. You do not need to click anything or interact with the CAPTCHA at all.

The extension is loaded from the `extensions/hlifkpholllijblknnmbfagnkjneagid` folder inside the cheat's installation directory and is injected into the WebView2 browser profile at startup.

<Note>
  The CAPTCHA solver is a third-party extension developed and maintained independently of NitroType Cheat v2. Its data handling practices are governed by its own privacy policy, available at [https://www.minirpa.net/captchasolver_privacy.html](https://www.minirpa.net/captchasolver_privacy.html). You can also find the extension on the [Chrome Web Store](https://chromewebstore.google.com/detail/captcha-solver-auto-hcapt/hlifkpholllijblknnmbfagnkjneagid).
</Note>

## Always Active

The ad blocker has no on/off toggle. Both layers — network blocking and DOM sweeping — activate automatically the moment the cheat window opens and remain active for the entire session. There is nothing you need to enable or configure.
