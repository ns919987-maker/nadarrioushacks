Every time you launch NitroType Cheat v2, the app silently contacts the update server to confirm you are running the latest release. This ensures you always have access to the most recent bug fixes and community-contributed improvements without needing to check manually.

## How Update Checks Work

On startup, the app sends a request to the update server and compares the live version against the version you have installed (`4.6.3`):

- **If the versions match** — no prompt is shown and the app opens normally.
- **If a newer version is available** — a dialog prompts you with a link to download the new installer.
- **If the update server is unreachable** — either because your internet connection is down or the server is temporarily offline — an error dialog is displayed to let you know the check could not complete. The app continues to run normally regardless; the update check failure does not block any features.

## How to Update

When the app tells you a new version is available, follow these steps:

<Steps>
  <Step title="Open the releases page">
    Click the link in the update prompt, or go directly to [https://github.com/kgsensei/NitroTypeHack2/releases/latest](https://github.com/kgsensei/NitroTypeHack2/releases/latest).
  </Step>
  <Step title="Download the installer">
    On the releases page, click `nitroTypeInstaller.exe` to download the latest installer.
  </Step>
  <Step title="Close the current version">
    Fully close the running instance of NitroType Cheat v2 before running the new installer.
  </Step>
  <Step title="Run the new installer">
    Launch the downloaded `nitroTypeInstaller.exe` and follow the on-screen prompts to complete the installation.
  </Step>
</Steps>

## Checking for Updates Manually

There is no in-app button to trigger a manual update check. If you want to check without restarting the app, visit [https://github.com/kgsensei/NitroTypeHack2/releases/latest](https://github.com/kgsensei/NitroTypeHack2/releases/latest) and compare the version listed there against the version shown in the cheat's title bar (`NitroType Cheat v4.6.3`). If the release page shows a higher version number, follow the update steps above.

<Note>
  NitroType Cheat v2 is a discontinued project. The original developer is no longer actively building new features, but community pull requests are still reviewed and merged when submitted. New releases do appear occasionally — keeping the app up to date ensures you benefit from any community fixes that have been accepted.
</Note>
