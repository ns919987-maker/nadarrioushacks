NitroType Cheat v2 is a free, source-available Windows desktop application that automates typing in [NitroType](https://nitrotype.com) races. Instead of relying on browser extensions or external scripts, it opens NitroType inside an embedded browser window and simulates keyboard input directly — letting you reach speeds that no human typist could match. Whether you want to experiment with how the game handles automated input or simply explore how a typing-game cheat is built, NitroType Cheat v2 gives you full control over speed, accuracy, and automation behavior.

## What Is NitroType Cheat v2?

NitroType Cheat v2 is a .NET WinForms application powered by the Microsoft WebView2 Runtime. When you launch it, it opens NitroType.com inside an embedded browser window — no separate tab or external browser required. During a race, the app reads the race text from the page and dispatches simulated keystroke events directly to the embedded browser using the Chrome DevTools Protocol, as if a real keyboard were being used.

Because it operates entirely within its own embedded browser, NitroType Cheat v2 never asks for your NitroType username, password, or any account credentials. You log in to NitroType yourself inside the embedded browser, and your session remains under your control at all times.

## System Requirements

To run NitroType Cheat v2, your machine must meet the following requirements:

- **Windows** operating system (the app is a .NET WinForms desktop application and does not run on macOS or Linux)
- **Microsoft WebView2 Runtime** installed — this is the embedded browser engine the app depends on; many Windows machines already have it, but if yours does not, you will be prompted to install it
- A **NitroType account** to log in to inside the embedded browser
